Task API — Documentación

Task API permite gestionar tareas mediante peticiones HTTP.

Endpoints disponibles

  • GET /tasks
  • GET /tasks/{id}
  • POST /tasks
  • PUT /tasks/{id}
  • DELETE /tasks/{id}

Pasos para realizar una petición

  1. Obtener el token de autenticación.
  2. Crear la petición HTTP.
  3. Añadir las cabeceras necesarias.
  4. Enviar la petición.
  5. Procesar la respuesta.

Parámetros

id
Identificador único de la tarea.
title
Título o nombre de la tarea.
completed
Indica si la tarea ha sido completada.
createdAt
Fecha y hora en la que se creó la tarea.

Estructura de una tarea

  • Identificación
    • id
  • Información
    • title
    • completed
  • Fecha
    • createdAt
