Introducción

WeatherAPI es una API ficticia que permite consultar información meteorológica de diferentes ciudades.

Puedes consultar la documentación externa sobre desarrollo web para obtener más información.

Autenticación

Para utilizar la API es necesario proporcionar una clave de autenticación en cada petición.

Consulta nuestra política de seguridad .

Endpoint de usuarios

Este endpoint permite obtener información sobre los usuarios registrados.

Ejemplo:

GET /api/usuarios

Endpoint de ciudades

Este endpoint permite consultar información meteorológica de diferentes ciudades.

Ejemplo:

GET /api/ciudades

Política de seguridad

Las claves de acceso deben mantenerse privadas y no deben compartirse públicamente.
