Glosario de desarrollo web

Algunos conceptos fundamentales utilizados en el desarrollo de aplicaciones web.

HTML
Lenguaje de marcado utilizado para estructurar el contenido de una página web.
CSS
Lenguaje utilizado para definir la presentación, estilos y diseño de una página web.
JavaScript
Lenguaje de programación utilizado para añadir comportamiento e interactividad a las páginas web.
API
Interfaz que permite que diferentes aplicaciones o sistemas puedan comunicarse entre sí.
HTTP
Protocolo utilizado para la comunicación entre clientes y servidores en la web.
Git
Sistema de control de versiones utilizado para gestionar los cambios realizados en un proyecto.
